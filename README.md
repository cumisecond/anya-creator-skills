# Anya Creator Skills

10 legal Gemini skills for motion, 3D galleries, light, sound and photo stories — built by Anya for olieolay / Instanusantara.

No jailbreak, no safeguard bypass. Official tools only.

## Skills

- **anya-creator** — multi-talent creator skill for Gemini Pro (motion, 3D, light, sound, web, video)
- **audio-caption-sync** — sync audio with captions / subtitles
- **gsap-scroll-cinema** — GSAP scroll-driven cinematic pages
- **instagram-creator-olieolay** — Instagram creator workflow for @olieolay
- **motion-design-director** — motion design direction
- **museum-light-designer** — museum / gallery lighting design
- **particle-morph-landing** — particle-morph landing pages
- **photo-story-teller** — documentary photo-story telling
- **threejs-gallery-builder** — Three.js 3D gallery builder
- **video-teaser-maker** — short teaser video maker

Each skill is a folder with a `SKILL.md`.

## Use

Copy a skill folder into Gemini CLI / Antigravity / Claude Code skills, or use the Anya Creator Gem in the Gemini app.

Tagline, exact: `Explore Indonesia Through Instanusantara`
